Step-1: 
- Create DB schema using dbdaigram.io
- Export DB schemas in postgres format

Step-2:
- Install docker
- Pull postgres image from docker hub
- docker pull postgres:19rc1-alpine3.23
- docker pull <image>:<tag>

Step-3:
- Run postgres container (its an instance of an image)
- Docker Image is a blueprint, and Docker Container is a running instance created from that blueprint.
- docker run 

// Run the container
- docker run --name postgres19c -p 5432:5432 -e POSTGRES_PASSWORD=admin -d postgres


// Run the cmd inside container
- docker exce -it <container_name_or_id> <cmd> [args]

//******* access postgres shell using this cmd****
- docker exec -it postgres19c psql -U postgres


// View container logs
- docker logs <container_name_or_id>

// view table GUI by tablePlus

Step-4:
- Install golang DB migration library
- brew install golang-migrate
- test: migrate -version

// create migration:
- migrate create -ext sql -dir db/migration -seq init_scheam
- Paste all the sql code generated by dbdaigram.io in up migration file
- Write the drop cmd in down migration file

// Docker cmd 
- docker stop postgres19c //stop the container
- docker ps -a // list of all container
- docker start postgres19c //start a container by name

// to access the docker shell (cmd) 
- docker exec -it postgres19c /bin/sh  
//👆 postgres19c name of the container and /bin/sh is a shell

docker exec -it postgres19c createdb
